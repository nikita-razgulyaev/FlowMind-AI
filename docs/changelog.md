# История изменений

## Версия 1.0 (ноябрь 2026)

Первый релиз с документацией.

### Редактор

- Данные между шагами без ручного набора ссылок: выпадающие списки соединённых шагов, по умолчанию выбран предыдущий шаг; пункт «Ручной ввод» для своих значений.
- Вставка данных в текстовые поля (задание нейросети, сообщения, письма) кнопкой «Вставить» с понятными подписями ссылок.
- Реальные примеры значений из прошлого запуска в списках выбора.
- Проверка сценария: кнопка «Проверить», проверка при сохранении, значки предупреждений на шагах.
- Проверка одного шага на тестовом тексте.
- Подсказки к шагам на палитре всегда помещаются на экран.
- Линии связей стали на 0,5 px толще. Подсказка по удалению связи добавлена в обучение.
- Подтверждение при выходе из аккаунта.
- Значок с книгами в боковой панели и ссылка «Документация» на странице о сервисе.

### Новые шаги без нейросети

- **Условие** в режиме «Простое условие»: правила «содержит», «равно», «больше», «пусто» и др.
- **По ключевым словам**: классификация обращений по заданным словам.
- **Собрать текст**: шаблон со вставками данных.
- **Обработка текста**: добавлены «Найти число», «Заменить текст», «Первая буква заглавная», «Каждое слово с заглавной», «Склеить в одну строку», «Сегодняшняя дата», «Текущие дата и время».

### ИИ-помощник

- Исправлены пустые ответы: увеличен лимит длины ответа, при пустом ответе включается запасная модель.
- Ссылки на шаги в сгенерированных сценариях проверяются и исправляются автоматически.
- Помощник знает о новых шагах и предпочитает шаги без нейросети там, где она не нужна.

### Нейросеть

- Параметр «Temperature» переименован в понятное «Креативность ответа» с подписями «Точнее» и «Свободнее».

### Документация

- Встроенный сайт документации (VitePress) по адресу `/help/`: руководство, справочник по шагам, установка, API, безопасность.

## Что входит в продукт

- Визуальный редактор сценариев, 20 шагов (из них 5 способов запуска).
- Облачный режим: регистрация, тарифы, оплата (демонстрационная и ЮKassa), административная панель.
- Локальный режим: без регистрации и лимитов, локальные модели Ollama.
- Подключения: Telegram, Google, Яндекс, Mail.ru, любая почта по паролю приложения, OpenAI-совместимые API.
- Готовые шаблоны сценариев.

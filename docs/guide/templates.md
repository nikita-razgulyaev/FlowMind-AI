# Готовые шаблоны

Страница **«Готовые шаблоны»** содержит заготовки типовых сценариев. Выберите шаблон и нажмите кнопку создания: сервис создаст ваш собственный сценарий с этими шагами, который можно менять как угодно.

| Шаблон | Что делает |
|---|---|
| **Telegram-бот поддержки** | Отвечает клиентам в Telegram вежливо и по делу на каждое сообщение |
| **Запись лида в Google Sheets** | Достаёт имя, контакт и потребность из сообщения, добавляет строку в таблицу и подтверждает клиенту |
| **Саммари встречи + action items** | Ручной запуск: вставляете текст встречи, получаете краткий итог и список задач |
| **Квалификация лида** | Извлекает данные, оценивает лид по шкале 1–10, пишет в таблицу, горячим и тёплым лидам отвечает по-разному |
| **Классификатор обращений** | Определяет тип (поддержка, продажа, жалоба, другое), отвечает по типу, ведёт журнал в таблице |
| **Ответы на частые вопросы** | Бот в Telegram отвечает строго по вашей базе знаний (график, цены, доставка) |
| **Приём обращений по заказу** | Находит номер заказа и телефон без нейросети, записывает обращение в таблицу, подтверждает клиенту |
| **Ответы на входящие письма** | Читает новые письма, готовит вежливый ответ и отправляет его |
| **Заявки с почты: в таблицу и автоответ** | Находит телефон и номер заказа без нейросети, записывает в таблицу, отвечает клиенту |
| **Сортировка писем по темам** | Определяет тему письма, готовит ответ нужного тона и отправляет |

## После создания

1. Откройте сценарий и просмотрите шаги.
2. В шагах, которым нужны подключения (Telegram, почта, Google), выберите свои: [подключения](/guide/connections).
3. Замените тексты на свои: например, в шаблоне «Ответы на частые вопросы» вставьте свою базу знаний в шаг «Готовый текст».
4. Нажмите [«Проверить»](/guide/checking), затем **«Запустить»**.

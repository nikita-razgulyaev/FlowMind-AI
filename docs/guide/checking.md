# Проверка сценария и шага

Чтобы ошибки находились до запуска, а не во время него, в редакторе есть две проверки.

## Проверка сценария

Кнопка **«Проверить»** в верхней панели показывает список проблем всего сценария. Рядом с названием кнопки отображается число найденных проблем, а на проблемных шагах появляется значок предупреждения: наведите на него курсор, чтобы увидеть причину. Список проблем конкретного шага также виден в верхней части его панели настроек.

Проверка срабатывает и **при сохранении**: если найдены ошибки, откроется окно со списком. Из него можно перейти к нужному шагу (**«Перейти к шагу»**), вернуться к исправлению (**«Исправить»**) или сохранить как есть (**«Всё равно сохранить»**).

### Что проверяется

| Проблема | Уровень |
|---|---|
| В сценарии нет шагов | Ошибка |
| Не заполнено обязательное поле шага (задание нейросети, адрес сервиса, текст сообщения и др.) | Ошибка |
| Условие заполнено не полностью | Ошибка |
| Не выбрано действие в «Обработке текста» | Ошибка |
| Не выбрано подключение (Telegram, почта, таблицы, календарь) или оно было удалено | Ошибка |
| Ссылка `{...}` ведёт на несуществующий шаг | Ошибка |
| Шаг ссылается на собственный результат | Ошибка |
| Нет шага запуска | Предупреждение |
| Шаг ни с чем не соединён | Предупреждение |
| Ссылка ведёт на шаг, не соединённый с текущим выше по цепочке: данные могут быть не готовы | Предупреждение |
| У ветки нет следующего шага: при таком результате сценарий закончится | Предупреждение |

**Ошибки** почти наверняка приведут к сбою при запуске. **Предупреждения** указывают на подозрительные места, но не мешают сохранению.

## Проверка одного шага

В панели настроек шагов, которые ничего не отправляют наружу, есть раздел **«Проверить шаг»**. Он выполняет только этот шаг на тестовом тексте и показывает результат, а для шагов с ветвлением ещё и ветку, по которой пойдёт сценарий.

1. Откройте панель настроек шага и раскройте **«Проверить шаг»**.
2. В поле **«Тестовый текст»** введите то, что должно попасть в `{input}`. Если сценарий уже запускался, поле заполнено текстом последнего запуска.
3. Нажмите **«Проверить»**.

Если шаг использует данные предыдущих шагов, они берутся из **последнего запуска сценария**. Если сценарий ещё не запускался, сначала запустите его целиком.

### Какие шаги можно проверить

Только те, у которых нет побочных эффектов:

- Обработка текста, Собрать текст, Готовый текст, Переменные, Показать результат;
- Условие, Выбор варианта, По ключевым словам;
- Запрос к сервису **только методом GET**.

Шаги, которые отправляют сообщения и письма, пишут в таблицы и календарь или используют нейросеть, проверяются только при запуске всего сценария: так вы не отправите клиенту тестовое сообщение и не потратите лимит нейросети.

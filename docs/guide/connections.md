# Подключения

Страница **«Подключения»** хранит доступы к внешним сервисам. Секреты (ключи, токены, пароли) **шифруются** и в интерфейсе показываются только в замаскированном виде. Подключение выбирается в настройках шага, которому оно нужно.

## Какие подключения есть

| Подключение | Что нужно | Для чего |
|---|---|---|
| **Hugging Face** | API-ключ | Нейросеть и ИИ-агент (поддерживает инструменты) |
| **OpenAI-совместимый API** | Base URL и API-ключ | OpenAI, OpenRouter, Groq и другие совместимые провайдеры |
| **Telegram-бот** | Токен бота | Приём сообщений и ответы клиентам |
| **Google Таблицы** | Вход через Google | Шаг «Таблицы» |
| **Яндекс Таблицы** | Вход через Яндекс | Шаг «Таблицы» (доступ к файлам на Диске) |
| **Google Календарь** | Вход через Google | Шаг «Календарь» |
| **Яндекс Календарь** | Данные доступа к календарю | Шаг «Календарь» |
| **Gmail**, **Яндекс Почта**, **Почта Mail.ru** | Вход через аккаунт, пароль не нужен | Приём и отправка писем |
| **Почта по паролю приложения** | Почтовый сервис, адрес, пароль приложения | Outlook, корпоративная почта и другие, у которых нет входа через аккаунт |

Для входа через аккаунт Google, Яндекс или Mail.ru администратор сервиса должен настроить OAuth: [установка](/admin/configuration#oauth-google-яндекс-mail-ru).

## Telegram {#telegram}

1. В Telegram откройте [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Укажите название и имя бота, получите **токен** вида `123456:ABC-DEF…`.
3. В сервисе: **Подключения → Telegram-бот** → вставьте токен и сохраните.
4. В сценарии используйте шаг **«Сообщение в Telegram»** для приёма и **«Ответ в Telegram»** для ответа, выберите это подключение.
5. **Включите сценарий.**

Один и тот же бот используется и для приёма, и для отправки. Чтобы публиковать в канал, добавьте бота в канал администратором и укажите идентификатор канала в шаге **«Ответ в Telegram»**.

Сервис получает сообщения одним из двух способов: через webhook (для сервиса с публичным адресом) или опросом Telegram (для локального запуска). Выбор автоматический, а при необходимости задаётся настройкой `TELEGRAM_MODE`: [переменные окружения](/admin/configuration).

## Почта

Рекомендуемый способ: **вход через аккаунт** (Gmail, Яндекс, Mail.ru). Пароль сервису не передаётся, доступ можно отозвать в настройках аккаунта.

Если у почты нет такого входа, выберите **«Почта по паролю приложения»**: укажите почтовый сервис (есть готовые настройки для Gmail, Mail.ru, Яндекс), адрес и **пароль приложения**, а не основной пароль от ящика. Пароль приложения создаётся в настройках безопасности почтового сервиса.

## Таблицы и календарь

Подключение выполняется кнопкой **«Войти через Google»** (или Яндекс). Сервис запрашивает доступ только к Таблицам или только к Календарю. В шаге нужно указать таблицу (идентификатор или адрес) и диапазон либо календарь.

## Нейросеть: свои ключи

В облачном сервисе по умолчанию используются модели платформы. Если в шаге **«Нейросеть»** или **«ИИ-агент»** выбрать режим **Cloud** и подключение с вашим ключом, запросы пойдут через вашего провайдера: удобно, если нужен конкретный сервис или своя квота. Возможность использовать свои API-ключи указана в тарифах «Про» и «Бизнес».

В локальной версии нейросеть работает через Ollama: [установка](/admin/installation#локальный-запуск).

## Безопасность подключений

- Секреты хранятся в зашифрованном виде.
- Подключения видны только их владельцу.
- Удаление подключения немедленно прекращает доступ. Шаги, которые его использовали, [проверка сценария](/guide/checking) пометит как требующие нового подключения.

# Запуск и история

## Способы запуска

| Способ | Как работает |
|---|---|
| **Вручную** | Кнопка **«Запустить»** в редакторе. Выполняется один раз на тестовых данных из шага запуска. Перед этим сценарий сохраняется, чтобы выполнялось именно то, что на холсте |
| **Сообщение в Telegram** | Сценарий запускается, когда клиент пишет вашему боту. Нужен [включённый сценарий](#включение-сценария) и подключённый бот |
| **Новое письмо** | Сервис периодически проверяет подключённую почту и запускает сценарий на каждое новое письмо |
| **Вызов по ссылке** | Другая система обращается к ссылке сценария (webhook), например форма на сайте |
| **По расписанию** | Через равные промежутки времени. В облаке интервал не меньше 5 минут |

### Включение сценария

Сценарий, запускаемый событиями (Telegram, почта, ссылка, расписание), нужно **включить**. Выключенный сценарий запускается только вручную. Число одновременно включённых Telegram-сценариев зависит от [тарифа](/guide/plans).

## Тестовые данные

При запуске кнопкой **«Запустить»** данные для шага запуска берутся из его настроек:

- у шагов **Ручной запуск** и **Сообщение в Telegram** — «Тестовое сообщение для кнопки «Запустить»», которое подставляется в `{input}`;
- у шага **Сообщение в Telegram** дополнительно «Тестовый chat_id» — куда отправлять ответ при проверке.

## Журнал последнего запуска

Кнопка **«Журнал»** в редакторе показывает, что сделал каждый шаг: его настройки на момент запуска и результат. Если шаг завершился ошибкой, в результате видна причина. Из журнала берутся и реальные примеры значений в [списках выбора данных](/guide/data-between-steps#реальные-значения-из-прошлого-запуска).

## История запусков

Страница **«История запусков»** хранит все запуски сценариев.

| Поле | Значение |
|---|---|
| Статус | `running` — выполняется, `success` — успешно, `failed` — ошибка, `cancelled` — остановлен |
| Источник | Вручную, Telegram, почта, расписание, ссылка |
| Время | Начало и окончание |
| Подробности | Журнал по шагам: входные настройки и результат каждого шага |

Запуски можно удалять. В облаке старые записи удаляются автоматически по сроку хранения тарифа: 14 дней на «Бесплатно», 60 на «Про», 180 на «Бизнес».

## Остановка

Выполняющийся сценарий можно остановить кнопкой **«Остановить»**: шаги, которые ещё не начались, не выполнятся. Статус запуска станет `cancelled`.

## Ограничения выполнения

| Ограничение | Значение по умолчанию |
|---|---|
| Максимальное время одного запуска | 120 секунд |
| Шагов в одном сценарии | до 60 |
| Одновременных запусков на пользователя | до 3 |

В облаке запрос из шага **«Запрос к сервису»** не может обращаться во внутреннюю сеть и на адреса `localhost`: это защита от злоупотреблений.

## Что считается ошибкой шага

Шаг помечается как завершившийся ошибкой, если его результат содержит сообщение об ошибке (например, сервис недоступен, неверный токен, нет подключения). Сообщение об ошибке видно в журнале.

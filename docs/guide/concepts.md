# Основные понятия

## Сценарий

**Сценарий** — это набор шагов и связей между ними. Один сценарий решает одну задачу: например, «ответить клиенту в Telegram» или «записать заявку в таблицу». Сценарии хранятся на странице **«Мои сценарии»**.

Сценарий может быть **включён** (запускается сам, когда наступило событие запуска) или **выключен** (запускается только вручную кнопкой **«Запустить»** для проверки).

## Шаг

**Шаг** — одна операция. Шаги делятся на группы, которые видны на вкладках сверху:

| Вкладка | Что делают шаги |
|---|---|
| **Запуск** | Определяют, когда стартует сценарий: вручную, по сообщению в Telegram, по письму, по ссылке, по расписанию |
| **Нейросеть** | Пишут текст нейросетью или поручают агенту самому выбирать инструменты |
| **Ветвление** | Направляют сценарий по разным путям, обрабатывают и собирают текст, показывают результат |
| **Сервисы** | Обращаются к другим сайтам, отправляют сообщения и письма, пишут в таблицы и календарь |

Полный список с настройками: [справочник по шагам](/steps/).

## Связь

**Связь** — линия между двумя шагами. Она означает: «после первого шага выполнить второй». Связь создаётся протягиванием от точки справа у одного шага к точке слева у другого. Удалить связь можно, нажав на неё и клавишу **Backspace** или **Delete**.

Шаги выполняются в порядке связей, слева направо. Шаг без входящих связей, кроме шагов запуска, не получит данные и не выполнится.

## Ветка

Шаги **Условие**, **Выбор варианта** и **По ключевым словам** имеют несколько выходов, называемых **ветками**:

- **Условие** — две ветки: `true` (условие выполнено) и `false` (нет).
- **Выбор варианта** — по ветке на каждый вариант и ветка `default`, если ни один не подошёл.
- **По ключевым словам** — по ветке на каждый тип и одна ветка для случая, когда ни одно слово не найдено (по умолчанию «другое»).

Выполняется только та ветка, которую выбрал шаг. Остальные пропускаются, и в журнале они помечаются как пропущенные.

## Данные запуска

Каждый сценарий стартует с данными, которые есть сразу:

| Данные | Что это | Когда доступны |
|---|---|---|
| `{input}` | Текст запуска: сообщение клиента, текст письма, тест из шага запуска | Всегда |
| `{telegram_chat_id}`, `{telegram_username}`, `{telegram_first_name}` | Чат, логин и имя клиента | Запуск по сообщению в Telegram |
| `{email_from}`, `{email_from_name}`, `{email_subject}`, `{email_body}` | Адрес и имя отправителя, тема и текст письма | Запуск по письму |
| `{webhook}` | Данные, пришедшие по ссылке | Запуск по ссылке |

## Результат шага

Каждый выполненный шаг сохраняет **результат**, который можно использовать в следующих шагах. Результат — это текст (ответ нейросети, найденный номер) или набор полей (ответ сервиса: код ответа, текст, данные JSON). Обратиться к нему можно записью в фигурных скобках: `{id_шага}` или `{id_шага.поле}`.

::: tip Вам не нужно набирать ссылки вручную
В полях шагов есть выбор шага из списка и кнопка «Вставить». Редактор сам подставит правильную ссылку. Подробнее: [данные между шагами](/guide/data-between-steps).
:::

## Выполнение (запуск)

Каждый запуск сценария фиксируется в **истории**: статус, источник запуска (вручную, Telegram, почта, расписание, ссылка), время и подробный журнал по каждому шагу. Выполнение ограничено по времени (по умолчанию 120 секунд), числу шагов в сценарии (60) и числу одновременных запусков на пользователя (3). Подробнее: [запуск и история](/guide/runs).

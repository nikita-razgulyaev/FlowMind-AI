# Быстрый старт

В этом примере вы соберёте сценарий, который находит в тексте номер заказа и формирует ответ. **Нейросеть не нужна**, всё работает мгновенно и бесплатно.

::: info Перед началом
В облачном сервисе зарегистрируйтесь и войдите в аккаунт. В локальной версии регистрация не нужна: сервис сразу открывается по адресу `http://localhost:8000`.
:::

## 1. Создайте сценарий

1. Откройте страницу **«Мои сценарии»** и нажмите **«Новый сценарий»**.
2. Откроется холст: слева боковая панель навигации, сверху вкладки с шагами (**Запуск**, **Нейросеть**, **Ветвление** и др.), в центре рабочая область.

## 2. Добавьте шаги

Шаг добавляется кликом по его кнопке на панели вкладок. Добавьте по порядку:

1. Вкладка **Запуск** → **Ручной запуск**.
2. Вкладка **Ветвление**, группа **Текст и данные** → **Обработка текста**.
3. Там же → **Собрать текст**.
4. Вкладка **Ветвление**, группа **Результат** → **Показать результат**.

Если навести курсор на кнопку шага, появится подсказка: что делает шаг и пример.

## 3. Соедините шаги

Потяните от точки справа у одного шага к точке слева у следующего: **Ручной запуск → Обработка текста → Собрать текст → Показать результат**. Чтобы удалить связь, нажмите на неё и затем **Backspace** или **Delete**.

## 4. Настройте шаги

Нажмите на шаг: справа откроется панель настроек.

**Ручной запуск.** В поле тестового текста впишите: `Где мой заказ? Номер 1234`.

**Обработка текста.**
- Действие: **Найти номер заказа**.
- Исходный текст: в списке уже выбран предыдущий шаг (**Ручной запуск**).

**Собрать текст.** В поле шаблона напишите:

```text
Здравствуйте! Ваш заказ № проверяется. Мы ответим в течение часа.
```

Затем поставьте курсор после «№ », в строке под полем выберите шаг **Обработка текста** и нажмите **Вставить**. В тексте появится ссылка на результат этого шага (под полем она отображается понятной подписью).

**Показать результат.** Выберите шаг **Собрать текст** или оставьте значение по умолчанию.

## 5. Запустите

Нажмите **Запустить** в верхней панели. Шаги по очереди подсветятся, а результат появится в панели **Журнал**: найденный номер `1234` и готовый ответ.

::: tip Что дальше
- Замените **Ручной запуск** на **Сообщение в Telegram**, а **Показать результат** на **Ответ в Telegram**: получится рабочий бот. Для этого нужно [подключение Telegram](/guide/connections#telegram).
- Добавьте **Нейросеть**, чтобы ответ писался сам: [шаги с нейросетью](/steps/ai).
- Попросите [ИИ-помощника](/guide/ai-assistant) собрать такую цепочку вместо вас.
:::

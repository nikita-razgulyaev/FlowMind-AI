# Шаги ветвления

Эти шаги направляют сценарий по разным путям. У каждого несколько выходов-веток; выполняется только та ветка, которую выбрал шаг, остальные пропускаются. Все три шага можно [проверить отдельно](/guide/checking#проверка-одного-шага): проверка покажет, по какой ветке пойдёт сценарий.

## Условие

Проверяет условие и выбирает одну из двух веток: `true` (выполнено) или `false` (не выполнено). Есть два режима.

### Простое условие

Условие собирается из **правил** в форме. Каждое правило состоит из трёх частей: **что проверяем** (выбор шага из списка или ручной ввод), **как** (оператор) и **с чем сравнить**.

| Оператор | Когда подходит |
|---|---|
| содержит / не содержит | Текст включает (или не включает) фрагмент. Регистр не важен |
| равно / не равно | Точное совпадение, регистр не важен |
| начинается с / заканчивается на | Проверка начала или конца текста |
| больше / больше или равно / меньше / меньше или равно | Сравнение чисел (допустимы запятая и пробелы: `12 500,5`) |
| пусто / не пусто | Значение отсутствует или есть |
| подходит под шаблон | Проверка регулярным выражением |

Если правил несколько, выберите: условие выполнено, если подходит **каждое** правило (И) или **любое** (ИЛИ).

**Пример.** Ответить срочно, если в сообщении есть слово «срочно» или сумма заказа больше 10 000: два правила и режим «любое».

### Своё выражение

Для сложных случаев можно записать выражение вручную, например `{extract.score} >= 7`. Допустимы сравнения, арифметика и логические операции; вызов функций и обращение к чужим данным запрещены. Если выражение не удалось вычислить, результат считается `false`.

## Выбор варианта

Выбирает ветку по значению: у шага столько веток, сколько вы перечислили вариантов, и ещё одна ветка `default`.

| Настройка | Описание |
|---|---|
| Значение | Что сравниваем (выбор шага или ручной ввод) |
| Варианты | Названия веток через запятую или с новой строки |

Сначала ищется **точное совпадение** значения с вариантом, затем **вхождение** варианта в значение. Регистр и знаки препинания не учитываются. Если ничего не подошло, выбирается `default`.

::: tip Типичный сценарий
Нейросеть или шаг «Обработка текста» определяет тип обращения (`support`, `sales`, `complaint`), а «Выбор варианта» отправляет его по нужной ветке.
:::

## По ключевым словам

Определяет тип сообщения по словам, которые вы задаёте сами. **Нейросеть не нужна**, поэтому шаг мгновенный и не расходует лимит.

| Настройка | Описание |
|---|---|
| Что проверяем | Текст для анализа (выбор шага или ручной ввод) |
| Типы и ключевые слова | Каждый тип с новой строки: название, двоеточие, слова через запятую |
| Если ни одно слово не найдено | Название ветки для остальных случаев (по умолчанию «другое») |

```text
доставка: где заказ, трек, курьер
оплата: оплата, счёт, чек
возврат: вернуть, возврат
```

Сравнение идёт без учёта регистра и знаков препинания. Побеждает **первый подходящий тип** в порядке записи. Для каждого типа создаётся своя ветка, плюс ветка для случая «ничего не найдено».

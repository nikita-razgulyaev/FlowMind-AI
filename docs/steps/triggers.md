# Шаги запуска

Шаг запуска определяет, когда стартует сценарий. В одном сценарии обычно один шаг запуска. У шагов запуска нет входящих связей.

## Ручной запуск

Запускает сценарий кнопкой **«Запустить»** в редакторе. Подходит для проверки и для разовых задач.

| Настройка | Описание |
|---|---|
| Тестовое сообщение для кнопки «Запустить» | Текст, который попадёт в `{input}` при запуске |

**Данные для следующих шагов:** `{input}`.

## Сообщение в Telegram

Запускает сценарий, когда клиент пишет вашему боту. [Как подключить бота](/guide/connections#telegram).

| Настройка | Описание |
|---|---|
| Подключение | Telegram-бот из раздела «Подключения» |
| Тестовое сообщение | Текст для запуска кнопкой «Запустить» |
| Тестовый chat_id | Чат, в который уйдёт ответ при проверке кнопкой «Запустить» |

**Данные для следующих шагов:** `{input}` (текст сообщения), `{telegram_chat_id}`, `{telegram_username}`, `{telegram_first_name}`.

::: tip Ответ клиенту
Шаг [«Ответ в Telegram»](/steps/apps#ответ-в-telegram) без указанного чата отвечает именно тому клиенту, который написал.
:::

## Новое письмо

Запускает сценарий на каждое новое письмо в подключённой почте. Сервис периодически проверяет ящик.

| Настройка | Описание |
|---|---|
| Подключение | Почта из раздела «Подключения» |
| Интервал проверки | Как часто проверять ящик, в минутах (по умолчанию 5, не больше 1440; в облаке не меньше 5) |

**Данные для следующих шагов:** `{input}` (текст письма), `{email_from}`, `{email_from_name}`, `{email_subject}`, `{email_body}`.

## Вызов по ссылке

Запускает сценарий, когда другая система обращается к специальной ссылке (webhook). Например, форма на вашем сайте отправляет заявку.

Ссылка уникальна для сценария и подписана секретом: адрес вида `/api/webhooks/{номер сценария}/{подпись}`. Её можно скопировать в настройках шага. Данные запроса, присланные в формате JSON, доступны в `{webhook}`.

::: warning Храните ссылку в тайне
Кто знает ссылку, тот может запускать сценарий. Число обращений к ссылке ограничено по частоте.
:::

## По расписанию

Запускает сценарий через равные промежутки времени.

| Настройка | Описание |
|---|---|
| Интервал | Минут между запусками (по умолчанию 60; в облаке не меньше 5) |

::: info Расписание и перезапуск сервера
Счётчик интервала сбрасывается при перезапуске сервера.
:::

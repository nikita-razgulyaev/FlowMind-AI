# Текст и данные

Шаги этой группы работают с текстом без нейросети и без обращения к внешним сервисам. Их можно [проверить отдельно](/guide/checking#проверка-одного-шага) на тестовом тексте.

## Обработка текста

Находит нужное в тексте, очищает его или преобразует.

| Настройка | Описание |
|---|---|
| Действие | Что сделать с текстом (список ниже) |
| Исходный текст | Выбор шага из списка (по умолчанию предыдущий) или ручной ввод, например `{input}` |
| Шаблон поиска | Для «Найти по своему шаблону» и «Заменить текст». Для замены это то, что нужно заменить |
| На что заменить | Только для «Заменить текст». Можно оставить пустым: фрагмент удалится |
| Максимум символов | Только для «Обрезать до N символов» |

### Найти в тексте

| Действие | Что делает | Пример |
|---|---|---|
| Найти номер заказа | Находит номер после слов «заказ», «№», «#» или первое число из 4–12 цифр | «Где мой заказ? Номер 1234» → `1234` |
| Найти телефон | Находит номер телефона и приводит его к виду +79001112233 | «звоните 8 (900) 111-22-33» → `+79001112233` |
| Найти email | Первый адрес электронной почты | «пишите на ivan@mail.ru» → `ivan@mail.ru` |
| Найти дату | Находит дату и приводит её к виду ДД.ММ.ГГГГ | «от 05.11.26» → `05.11.2026` |
| Найти сумму | Находит сумму рядом со словами «руб.», «₽», «$», «€» | «12 500 руб» → `12500` |
| Найти ссылку | Первая ссылка, начинающаяся с http:// или https:// | «смотри https://example.com» → ссылка |
| Найти число | Находит первое число и приводит его к виду с точкой | «Итого 12 500,50 руб» → `12500.50` |
| Найти по своему шаблону | Для опытных: ищет по регулярному выражению. Если в шаблоне есть скобки, возвращается то, что внутри первых скобок | — |

Если ничего не найдено, результат пустой.

### Очистить

| Действие | Что делает |
|---|---|
| Очистить письмо | Убирает из письма цитаты предыдущей переписки и подпись, оставляет суть |
| Привести к простому виду | Строчные буквы без знаков препинания: «Support.» → «support». Удобно перед выбором варианта |
| Первая строка | Берёт только первую непустую строку |
| Обрезать до N символов | Оставляет только начало текста заданной длины |
| Убрать лишние пробелы | Убирает пробелы по краям и повторяющиеся пробелы внутри строки |
| Строчные буквы | Переводит весь текст в строчные |
| ЗАГЛАВНЫЕ буквы | Переводит весь текст в заглавные |

### Изменить и подставить

| Действие | Что делает |
|---|---|
| Заменить текст | Заменяет один фрагмент на другой везде в тексте |
| Первая буква заглавная | «привет мир» → «Привет мир» |
| Каждое слово с заглавной | «иван ПЕТРОВ» → «Иван Петров» |
| Склеить в одну строку | Переносы строк и лишние пробелы заменяются одним пробелом |
| Сегодняшняя дата | Подставляет дату вида ДД.ММ.ГГГГ (по времени сервера). Исходный текст не нужен |
| Текущие дата и время | Подставляет ДД.ММ.ГГГГ ЧЧ:ММ (по времени сервера). Исходный текст не нужен |

**Результат:** строка. При ошибке настройки результат начинается с `Text Error:`.

## Собрать текст

Собирает текст из шаблона: ответ клиенту, строку для таблицы, сообщение. Нейросеть не нужна.

| Настройка | Описание |
|---|---|
| Шаблон текста | Обычный текст со вставками данных других шагов |

Данные вставляются кнопкой **«Вставить»** под полем: поставьте курсор в нужное место, выберите шаг и поле. **Результат:** готовый текст.

```text
Здравствуйте, {имя}! Ваш заказ № принят. Мы свяжемся с вами по телефону.
```

## Готовый текст

Постоянный текст, который не меняется: база знаний для бота, шаблон письма, инструкция.

| Настройка | Описание |
|---|---|
| Текст | Любой текст |

**Результат:** этот же текст. Удобно подавать его в задание нейросети как справочник: «Отвечай только по этой информации».

## Переменные

Хранит несколько именованных значений: удобно, когда один и тот же набор (город, подпись, адрес) нужен в разных местах.

| Настройка | Описание |
|---|---|
| Значения | По одному на строку в формате `имя=значение` |

```text
город=Москва
подпись=Команда поддержки
```

**Результат:** набор полей. Значение доступно как `{id_шага.город}`. В значениях можно использовать данные других шагов.

## Показать результат

Выводит значение в журнал запуска: удобно для проверки сценария и как «последний» шаг цепочки.

| Настройка | Описание |
|---|---|
| Что показать | Текст со вставками данных. Если поле пустое, показывается результат последнего выполненного шага |

**Результат:** показанный текст.

# Шаги с нейросетью

Шаги этой группы используют языковую модель. Они расходуют [лимит «запусков с нейросетью»](/guide/plans): сценарий, в котором есть такой шаг, считается сценарием с нейросетью.

## Нейросеть

Пишет текст по вашему заданию. Результат — готовый текст, который можно отправить клиенту, записать в таблицу или обработать дальше.

| Настройка | Описание |
|---|---|
| Режим | **Cloud** — через облачного провайдера или модели платформы, **Local** — локальная модель Ollama |
| Подключение | Для режима Cloud: ключ своего провайдера (необязательно в облаке, если используются модели платформы) |
| Модель | Модель выбранного режима |
| Задание (промпт) | Что нужно сделать. В текст можно вставлять данные других шагов |
| Креативность ответа | От 0 до 1. Ниже — точнее и предсказуемее, выше — свободнее и разнообразнее. Для ответов по фактам лучше 0,2–0,4 |

**Результат:** текст ответа. Если модель недоступна или вернула ошибку, результат начинается с `LLM Error:`.

### Как писать задание

- Начните с роли и цели: «Ты вежливый оператор поддержки. Ответь клиенту кратко».
- Вставьте данные кнопкой **«Вставить»** под полем: сообщение клиента, найденный номер заказа, ответ сервиса.
- Задайте формат: «Ответь одним абзацем», «Верни только число».
- Если результат нужен в виде полей, попросите ответить JSON-объектом: так его проще обработать следующими шагами.

## ИИ-агент

Агент сам решает, какие инструменты вызвать, чтобы выполнить задачу. Инструментом может быть любой шаг, у которого заполнены название и описание инструмента.

| Настройка | Описание |
|---|---|
| Режим, подключение, модель | Как у шага «Нейросеть». Агент требует модель, которая поддерживает инструменты |
| Задание | Что должен сделать агент |
| Системная инструкция | Правила поведения агента |
| Максимум шагов размышления | Сколько раз агент может вызвать инструменты (от 1 до 10, по умолчанию 5) |
| Креативность ответа | Для агента лучше низкое значение: он увереннее выбирает инструменты |

### Как подключить инструмент

1. Соедините нижнюю точку агента (**«↓ инструменты агента»**) с нужным шагом: запросом к сервису, Telegram, таблицей, календарём или почтой.
2. В настройках этого шага появится блок **«Инструмент для ИИ-агента»**. Заполните:
   - **название инструмента** — латиницей, без пробелов (например, `get_rate`);
   - **описание для нейросети** — что делает инструмент и когда его вызывать: по нему агент решает, нужен ли вызов;
   - **какие данные нужны от клиента** — поля, которые агент должен передать (можно отметить обязательные).
3. Агент вызывает инструмент сам, подставляя данные в эти поля.

**Результат:** `{id_агента.answer}` — итоговый ответ агента.

::: warning Когда нужен агент
Агент медленнее и дороже обычной нейросети. Если порядок действий известен заранее, соберите цепочку из обычных шагов: это быстрее и предсказуемее.
:::

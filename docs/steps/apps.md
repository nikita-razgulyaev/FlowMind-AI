# Сервисы и отправка

Эти шаги обращаются к внешним сервисам или отправляют данные наружу. Поэтому они **не проверяются отдельно** (кроме запроса методом GET): запустите сценарий целиком, чтобы убедиться, что всё работает. Нужные подключения создаются в разделе «Подключения»: [подключения](/guide/connections).

## Запрос к сервису

Обращается к сайту или сервису по адресу (API) и возвращает ответ. Пример: получить курс валют, погоду, статус заказа из вашей системы.

| Настройка | Описание |
|---|---|
| Метод | `GET` — получить данные, `POST` — отправить данные |
| Адрес | Полный адрес `https://...`. Можно вставлять данные других шагов |
| Заголовки | Необязательно. Формат JSON, например `{"Authorization": "Bearer ..."}` |
| Тело запроса | Только для `POST`: JSON или обычный текст |

**Результат** (поля):

| Поле | Что внутри |
|---|---|
| `.status_code` | Код ответа |
| `.body` | Начало текста ответа |
| `.json` | Структура ответа, если сервис вернул JSON |

Пример: `{id_шага.json.rates.RUB}` — значение из JSON-ответа.

::: warning Ограничения
Ожидание ответа ограничено по времени. В облаке нельзя обращаться ко внутренней сети и на `localhost`. Заголовки с ключами не передаются на другой адрес при перенаправлении.
:::

## Ответ в Telegram

Отправляет сообщение через бота Telegram.

| Настройка | Описание |
|---|---|
| Подключение | Telegram-бот |
| Чат | Куда отправить. **Пусто** — тому клиенту, который запустил сценарий. Можно указать номер чата или канал |
| Сообщение | Текст со вставками данных |
| Ссылка на картинку | Необязательно: прикрепить изображение |

**Результат:** подтверждение отправки. Если не выбрано подключение или не указан чат, результат начинается с `Telegram Error:`.

## Отправить письмо

Отправляет письмо через подключённую почту.

| Настройка | Описание |
|---|---|
| Подключение | Почта (Gmail, Яндекс, Mail.ru или по паролю приложения) |
| Кому | Адрес получателя. **Пусто** — отправителю входящего письма (`{email_from}`) |
| Тема | Тема письма (до 300 символов; если пусто — «Без темы») |
| Текст письма | Текст со вставками данных |
| Ответить в той же переписке | Отправляет письмо как ответ на входящее (только когда сценарий запущен входящим письмом) |

**Результат:** `status` = `sent`, а также адрес и тема. Если адрес некорректен или доступ к почте истёк, результат начинается с `Email Error:`.

## Таблицы

Добавляет строку в таблицу.

| Настройка | Описание |
|---|---|
| Подключение | Google Таблицы или Яндекс Таблицы |
| Таблица | Google: идентификатор таблицы (часть адреса между `/d/` и `/edit`). Яндекс: путь к файлу на Диске |
| Диапазон | Только Google: лист и диапазон, по умолчанию `A1` |
| Значения | Значения строки **через запятую**, по одному на столбец, со вставками данных |

**Пример значений:** `{имя}, {телефон}, {сообщение}` — три столбца.

::: tip Запятая внутри значения
Запятая разделяет столбцы. Если в самом значении может быть запятая, обработайте его шагом «Обработка текста» (например, заменой запятой на точку с запятой).
:::

## Календарь

Создаёт событие в календаре.

| Настройка | Описание |
|---|---|
| Подключение | Google Календарь или Яндекс Календарь |
| Календарь | Google: идентификатор календаря (по умолчанию основной, `primary`). Яндекс: название календаря (пусто — основной) |
| Название события | Заголовок |
| Описание | Необязательно |
| Начало, Окончание | Дата и время начала и конца события |

Если начало или конец не указаны, результат начинается с `Calendar Error:`. Остальные ошибки (нет доступа, доступ истёк) тоже начинаются с `Calendar Error:`, а причина видна в журнале.

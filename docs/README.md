# Документация FlowMind AI

Сайт на [VitePress](https://vitepress.dev). Исходники страниц — Markdown-файлы в этой папке.

```bash
cd docs
npm install
npm run dev        # http://localhost:5174/help/
npm run build      # сборка в .vitepress/dist
```

В Docker-образе сайт собирается автоматически и публикуется сервисом по адресу `/help/`
(ссылки есть на лендинге и в боковой панели сервиса).

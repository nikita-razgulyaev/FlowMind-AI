# Установка

FlowMind AI можно запустить тремя способами. Если вы просто хотите попробовать сервис у себя, выбирайте локальный запуск в Docker.

| Способ | Для чего | Что понадобится |
|---|---|---|
| [Локальный запуск в Docker](#локальный-запуск) | Работа на своём компьютере с локальными моделями, без регистрации и лимитов | Docker |
| [Запуск из исходников](#запуск-из-исходников) | Разработка и отладка | Python 3.12, Node.js 22 |
| [Облачный режим](/admin/deployment) | Публикация сервиса для пользователей с регистрацией, тарифами и оплатой | Сервер или хостинг, домен |

## Локальный запуск

В этом режиме регистрация и лимиты отключены, а порт доступен только с вашего компьютера.

```bash
git clone <адрес репозитория>
cd FlowMind-AI
docker compose up --build
```

Сервис откроется по адресу **http://localhost:8000**. Вместе с ним запускается [Ollama](https://ollama.com) для локальных моделей. Модель по умолчанию — `qwen2.5` (меняется переменной `OLLAMA_MODEL`).

::: tip Документация внутри сервиса
Когда сервис запущен, эта документация доступна по адресу **http://localhost:8000/help/**, а также по значку с книгами в боковой панели.
:::

Необязательные настройки задаются в файле `.env` рядом с `docker-compose.yml`, например:

```ini
OLLAMA_MODEL=qwen2.5
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
```

Все данные (база SQLite, подключения) хранятся в томе Docker `flowmind-data`, поэтому не пропадают при перезапуске.

### Что нужно знать о локальном режиме

- В шагах «Нейросеть» и «ИИ-агент» режим **Local** использует Ollama, режим **Cloud**: свои подключения или модели платформы.
- Telegram работает через опрос (long polling), публичный адрес не нужен. Сообщения, присланные боту, пока сервис был выключен, пропускаются.
- Включить регистрацию и вход в локальном режиме можно переменной `AUTH_ENABLED=true` (например, для домашнего сервера).
- Порт публикуется только на `127.0.0.1`: в локальном режиме нет авторизации, не открывайте его в интернет.

## Запуск из исходников

### Бэкенд

```bash
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

База данных SQLite создаётся автоматически, миграции применяются при старте (`AUTO_MIGRATE=true`). Описание API открывается по адресу `http://localhost:8000/api/docs` (только в локальном режиме).

### Фронтенд

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется по адресу **http://localhost:5173**. Запросы `/api/*` проксируются на бэкенд (порт 8000).

### Документация

```bash
cd docs
npm install
npm run dev
```

Документация откроется по адресу **http://localhost:5174/help/**. Чтобы она открывалась по ссылкам из приложения в режиме разработки, запустите её как указано выше: dev-сервер фронтенда перенаправляет `/help` на этот порт.

## Проверка установки

- `GET /api/health` возвращает состояние сервиса (ответ `200`, если база данных доступна).
- `GET /api/config` возвращает режим работы (`local` или `cloud`), включена ли авторизация и доступные возможности.
- Откройте редактор и запустите сценарий «Ручной запуск → Показать результат».

## Обновление

1. Получите новую версию кода.
2. Пересоберите образ: `docker compose up --build`.
3. Миграции базы данных применятся автоматически при старте, ваши сценарии, подключения и история сохранятся.

Перед обновлением рекомендуется сделать копию тома с данными (для SQLite это файл `flowmind.db`).

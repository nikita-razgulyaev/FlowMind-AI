# Переменные окружения

Настройки задаются переменными окружения (или файлом `.env`). Имена не зависят от регистра. Если переменная не указана, действует значение по умолчанию.

## Режим работы и база данных

| Переменная | По умолчанию | Описание |
|---|---|---|
| `DEPLOYMENT_MODE` | `local` | `local`: без регистрации и лимитов; `cloud`: регистрация, тарифы, оплата |
| `AUTH_ENABLED` | зависит от режима | Включена ли авторизация: в `cloud` да, в `local` нет |
| `DATABASE_URL` | `sqlite+aiosqlite:///./flowmind.db` | Строка подключения. Для PostgreSQL: `postgresql://user:pass@host:5432/db` |
| `AUTO_MIGRATE` | `true` | Применять миграции Alembic при старте |
| `STATIC_DIR` | пусто | Папка со сборкой фронтенда и документации (в Docker-образе задана автоматически) |

## Безопасность и адреса

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SECRET_KEY` | `dev-insecure-change-me` | Секрет подписи токенов и ссылок. **В продакшене обязательно заменить** |
| `ENCRYPTION_KEY` | равен `SECRET_KEY` | Ключ шифрования секретов подключений. Лучше задать отдельный и **не менять**: иначе сохранённые подключения перестанут расшифровываться |
| `ACCESS_TOKEN_MINUTES` | `15` | Срок жизни токена доступа |
| `REFRESH_TOKEN_DAYS` | `30` | Срок жизни токена обновления |
| `COOKIE_SECURE` | авто | Отправлять cookie только по HTTPS |
| `CORS_ORIGINS` | `http://localhost:5173` | Разрешённые адреса фронтенда через запятую |
| `PUBLIC_BASE_URL` | пусто | Публичный адрес сервиса, например `https://flowmind.example.com`. Нужен для вебхуков, ссылок на вызов сценария и возврата с оплаты |
| `FRONTEND_URL` | `http://localhost:5173` | Адрес фронтенда для ссылок в письмах |

## Администратор и почта сервиса

| Переменная | По умолчанию | Описание |
|---|---|---|
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | пусто | Данные первого администратора. Создаётся при запуске в облачном режиме |
| `REQUIRE_EMAIL_VERIFICATION` | `false` | Требовать подтверждение адреса почты при регистрации |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM`, `SMTP_STARTTLS` | пусто / `587` / `true` | Почта для писем сервиса (подтверждение, сброс пароля) |
| `DEMO_MODE` | `false` | Показывать ссылки из писем прямо в ответе API и открывать описание API. **Только для демонстраций** |

## Контакты и обратная связь

Форма обратной связи включена в облачном режиме. Обращения сохраняются в базе и показываются в админ-панели, вкладка **«Обращения»**. Контакты выводятся в футере сайта и на странице `/contacts`; те, что не заполнены, не показываются.

| Переменная | По умолчанию | Описание |
|---|---|---|
| `SUPPORT_EMAIL` | пусто | Почта для связи |
| `SUPPORT_TELEGRAM` | пусто | `@name`, `name` или `https://t.me/name` |
| `SUPPORT_VK` | пусто | Ссылка на страницу или сообщество: `https://vk.com/...` (допускается и `vk.ru`) |
| `FORMSPREE_URL` | пусто | Адрес формы Formspree (`https://formspree.io/f/xxxxxxxx`). Если задан, копия каждого обращения уходит на почту. Принимаются только адреса `formspree.io`: опечатка не отправит данные на чужой сервер |
| `FEEDBACK_ENABLED` | `true` в облаке, `false` локально | Принудительно включить или выключить форму |

::: tip Если значение не применилось
Контакт с неверным форматом тихо пропускается, а при старте в журнале появляется предупреждение с названием переменной.
:::

## Оплата

| Переменная | По умолчанию | Описание |
|---|---|---|
| `PAYMENT_PROVIDER` | `mock` | `mock`: демонстрационная оплата без списаний; `yookassa`: реальная оплата |
| `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` | пусто | Данные магазина ЮKassa |
| `YOOKASSA_RECEIPTS` | `false` | Отправлять чек по 54-ФЗ вместе с платежом |
| `YOOKASSA_VAT_CODE`, `YOOKASSA_TAX_SYSTEM_CODE` | `1` / не задан | Параметры чека |

Для реальной оплаты укажите в личном кабинете ЮKassa адрес уведомлений: `<PUBLIC_BASE_URL>/api/billing/yookassa/webhook`.

## Нейросеть

| Переменная | По умолчанию | Описание |
|---|---|---|
| `LLM_MODE` | зависит от режима | `local`: Ollama; `cloud`: модели платформы |
| `OLLAMA_URL` | `http://localhost:11434` | Адрес Ollama |
| `OLLAMA_MODEL` | `qwen2.5` | Модель Ollama |
| `PLATFORM_LLM_PROVIDERS` | пусто | Цепочка моделей платформы: JSON-список, первая модель основная, остальные запасные. Записи без ключа или с адресом не по `https` пропускаются |
| `ROUTERAI_API_KEY` | пусто | Ключ провайдера по умолчанию |
| `PLATFORM_LLM_COOLDOWN_SECONDS` | `60` | На сколько отложить модель после сбоя (при повторных сбоях растёт, максимум 10 минут) |
| `AI_DAILY_CAP` | <!-- plans:cap -->`2500`<!-- /plans:cap --> (из `plans_config.py`) | Общий суточный потолок запросов к ключу платформы |
| `PLANS_FORCE_SYNC` | `false` | `true` — один раз перезаписать все тарифы значениями из `backend/app/plans_config.py` (затирает правки из админ-панели; после запуска уберите) |

Пример `PLATFORM_LLM_PROVIDERS`:

```json
[
  {"name": "main", "base_url": "https://routerai.ru/api/v1", "model": "qwen/qwen3.8-27b", "api_key_env": "ROUTERAI_API_KEY"},
  {"name": "backup", "base_url": "https://api.groq.com/openai/v1", "model": "llama-3.3-70b-versatile", "api_key_env": "GROQ_API_KEY"}
]
```

Ключ можно указать прямо (`api_key`) или через имя переменной (`api_key_env`). Необязательное поле `max_tokens` (по умолчанию 1500) задаёт длину ответа; для чата ИИ-помощника длина ответа автоматически увеличивается минимум до 4000, чтобы модели с «размышлениями» не возвращали пустой ответ. Если модель вернула пустой ответ, сервис переключается на следующую в цепочке.

## Telegram

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TELEGRAM_MODE` | `auto` | `auto`: сам выбирает; `webhook`: нужен публичный `PUBLIC_BASE_URL`; `polling`: опрос, публичный адрес не нужен; `off`: отключено |

## OAuth (Google, Яндекс, Mail.ru)

Нужен для входа через аккаунт в подключениях: Таблицы, Календарь, почта.

| Переменная | Описание |
|---|---|
| `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI` | Приложение Google. Адрес возврата: `<PUBLIC_BASE_URL>/api/oauth/google/callback` |
| `YANDEX_CLIENT_ID`, `YANDEX_CLIENT_SECRET`, `YANDEX_REDIRECT_URI` | Приложение Яндекс. Адрес возврата: `<PUBLIC_BASE_URL>/api/oauth/yandex/callback` |
| `MAILRU_CLIENT_ID`, `MAILRU_CLIENT_SECRET`, `MAILRU_REDIRECT_URI`, `MAILRU_MAIL_SCOPES` | Приложение Mail.ru. Адрес возврата: `<PUBLIC_BASE_URL>/api/oauth/mailru/callback`. Права почты по умолчанию: `userinfo mail.imap` |

Без этих ключей кнопка входа в подключениях сообщает, что сервис не настроен.

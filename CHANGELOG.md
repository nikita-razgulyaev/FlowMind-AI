# Изменения: OAuth-подключения, почта, обучение

- OAuth для Google (Таблицы, Календарь, Gmail), Яндекс и Mail.ru: общий модуль `services/oauth.py`, PKCE (Google), проверка выданных прав, автообновление токенов, пометка «нужен повторный вход» и кнопка «Войти заново», подпись аккаунта в карточке, отзыв доступа Google при удалении. Прежний адрес `/oauth/google/start` сохранён.
- Почта через OAuth (XOAUTH2) для Gmail, Яндекса и Mail.ru; вход по паролю приложения оставлен для Outlook и корпоративной почты.
- Telegram: токен проверяется через `getMe`, в карточке показывается имя бота; публикация в канал (`@имя` или ссылка t.me), отправка фото с подписью, понятные тексты ошибок.
- Новые шаги: «Обработка текста», «Новое письмо», «Отправить письмо».
- Новые шаблоны: ответы на частые вопросы, приём обращений по заказу, ответы на входящие письма, заявки с почты в таблицу, сортировка писем по темам.
- Обучение: интерактивная подсказка, пошаговое окно, кнопка в боковой панели. Единые термины и обращение на «Вы».
- Встроенный AI: все модели одним списком `PLATFORM_LLM_PROVIDERS`, основная по умолчанию — OrcaRouter `deepseek/deepseek-v4-flash-free` (ключ `ORCAROUTER_API_KEY`). Переменные `PLATFORM_LLM_API_KEY/BASE_URL/MODEL/FALLBACKS` и `HF_TOKEN` больше не используются. Автоматическое переключение на следующую модель списка при сбое, «охлаждение» упавшего провайдера, маскирование ключей в ошибках.
- Подключения: один диалог «что подключить → сервис → способ входа» (страница входа или пароль приложения); Outlook и корпоративная почта вынесены отдельно. Яндекс Календарь по CalDAV (пароль приложения), шаг «Календарь» работает и с Google, и с Яндексом; «Таблицы» и «Календарь» разделены в панели.
- Нейросеть и ИИ-агент: модель выбирается из списка (модели платформы из секретов, основная по умолчанию, либо модели своего подключения). Эндпоинт `GET /api/ai/models`.
- Панель: шаг «Ответ нейросети» переименован в «Нейросеть», «Показать результат» вынесен отдельно, вкладка «С чего начать» → «Запуск», убраны подписи под группами.
- Обучение: иллюстрации собраны из настоящих элементов редактора (иконки, подписи, панель, боковая панель), цепочка появляется по очереди и остаётся, словарь убран, крестик отделён фоном.
- Лендинг: новый заголовок, описание и схема «Почта → ИИ-агент → три ветки».
- Настройки: в облачной версии скрыты локальная модель и выбор режима.

# Изменения: движок в стиле n8n (v1.1)

- Ветвление: Condition (`true`/`false`) и Switch выполняют только выбранную ветку; связи Condition без метки работают как раньше.
- Новые ноды: Webhook, Schedule (интервал), Switch, Set. HTTP: headers, body, `{http_1.json.поле}`.
- Плейсхолдеры `{node.field}`; подстановка за один проход, лимит значения 500 → 4000 символов; dict/list подставляются как JSON (раньше — Python repr).
- Кнопка Run без модалки: «Тестовые данные» в настройках триггера.
- Шаблоны заменены на 5 новых (старые «Email Responder», «Саммари новостей», «Погодный советник» удалены).
- Редактор: описание воркфлоу открывается в модалке; нода «Текст» (вставка или файл); панель нод в стиле ленты Fusion 360 (вкладки, выпадающие списки); граф центрируется после загрузки; мини-карта повторяет вид нод.
- Лог в редакторе показывает историю запусков воркфлоу (раскрывающиеся записи) и кнопку «Очистить логи»; клик по запуску в «Истории выполнений» открывает воркфлоу с этим запуском в логе (исправлен белый экран из-за рендера объекта строки лога).
- Навигация лендинга: убран «Личный кабинет» (остался в боковой панели приложения), добавлен «Как работает» (скролл к блоку).
- Лендинг: «Тарифы» в шапке плавно скроллит к блоку тарифов (в том числе при повторном клике), логотип в шапке перезагружает страницу.
- Отмена и повтор правок графа: Ctrl+Z / Ctrl+Shift+Z (Ctrl+Y), работает на любой раскладке и не мешает отмене текста в полях ввода (до 50 шагов: добавление и удаление нод и связей, перемещение, правки настроек).
- Убрана кнопка «Тест»; в заголовке ноды иконка и название больше не сжимаются и не переносятся, длинный id обрезается.
- Запуск и остановка: у воркфлоу с триггерами (Telegram / Webhook / Schedule) кнопка «Запустить» ↔ «Стоп» (`POST /workflows/{id}/activate|deactivate`), рядом «Тест» — разовый запуск; у остальных Run превращается в «Стоп» и отменяет выполнение (`POST /executions/{id}/cancel`, статус `cancelled`). Состояние хранится на сервере и подхватывается после обновления страницы (идущий запуск продолжает отображаться).
- Telegram-триггер реагирует только на сообщения, отправленные после запуска воркфлоу (`workflows.activated_at`, миграция 0002; при первой регистрации вебхука накопленные сообщения сбрасываются). Принимает сообщения от всех пользователей, если `allowed_chat_ids` пуст.
- Новые воркфлоу и шаблоны создаются остановленными; чекбокс «Активен» заменён индикатором и кнопкой запуска.
- Живой прогресс запуска: Run выполняется в фоне (`POST /workflows/{id}/execute-async`), редактор опрашивает `GET /executions/{id}/progress`; на нодах краткий статус (выполняется / готово + время / ошибка / пропущена), по связям «течёт» анимация, невыбранные ветки тускнеют.
- В логе `**текст**` отображается жирным без звёздочек.
- Шапка и лента нод компактнее (~190 px).
- AI-чат знает новые ноды и сохраняет метки веток.

# Изменения: превращение в SaaS (v1.0)

## Новое
- Аккаунты (регистрация, вход, сброс пароля, подтверждение email), личный кабинет, админ-панель, лендинг.
- Тарифы Бесплатно / Про / Бизнес, помесячная и годовая оплата, лимиты и счётчики использования.
- Платежи: `PaymentProvider` (имитация для демо + ЮKassa), автопродление, апгрейд с зачётом, отложенное понижение.
- Telegram-триггер (webhook в облаке, long polling локально).
- Рабочий AI-чат в редакторе (сборка графа по описанию).
- Режимы `cloud` / `local`, Alembic-миграции, PostgreSQL, единый Docker-образ, `render.yaml`, `docker-compose.prod.yml`.

## Рефакторинг и изменения поведения (требуют внимания)
- **Все API-маршруты теперь под `/api`** (раньше backend отдавал их с корня, а `/api` срезал прокси). Google OAuth callback: `/api/oauth/google/callback` — обновите redirect URI в Google Cloud Console и в `.env`.
- **`eval` в Condition-ноде заменён** безопасным интерпретатором выражений (`services/safe_eval.py`): при многопользовательской работе `eval` давал возможность выполнить произвольный код на сервере. Поддерживаются сравнения, `and/or/not`, арифметика, `len/str/int/float/min/max/round`, методы строк `lower/upper/strip/startswith/endswith/isdigit`.
- **Секреты подключений шифруются** в БД (`enc:`-значения). Старые открытые значения читаются как есть и шифруются при пересоздании подключения.
- **Hugging Face:** прямой вызов `api-inference.huggingface.co` заменён на OpenAI-совместимый роутер (`router.huggingface.co/v1`) — теперь и LLM-, и Agent-ноды работают через него, включая tool calling. Подключение типа `huggingface` теперь поддерживает агентов.
- **Режим Cloud без выбранного подключения** использует AI сервиса (`PLATFORM_LLM_*`); поле «модель» в этом случае игнорируется (модель задаёт сервис).
- **HTTP-нода:** не следует редиректам автоматически (каждый переход проверяется), в облаке блокирует внутренние адреса.
- **Таймстемпы логов** выполнения теперь в ISO-формате (раньше — внутренний счётчик event loop).
- Старые файлы `docker-compose.cloud.yml`, `frontend/Dockerfile`, `frontend/nginx.conf`, `backend/Dockerfile` удалены: их заменяют корневой `Dockerfile` и compose-файлы.
- Зависимости backend обновлены до проверенных версий (Python 3.12).
- Отдельный `_hf_generate` и `CLOUD_PROVIDER` удалены за ненадобностью.
